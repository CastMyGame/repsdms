## Confirmed gaps that remain gated

All replacement-save roots above can lose an unknown field before model adoption and can overwrite immutable ownership from stale input even after a simple model addition. Merely adding BeforeSave database lookups would not make replacement atomic and could create mapping/repository dependency cycles. They remain deferred rather than receiving a misleading callback guard.

Employee/Student targeted operators preserve ownership, but direct MongoTemplate.save/replace or inherited destructive repository helpers are not globally intercepted by this PR. Current authorized application paths were reviewed; future direct writers must use the protected path or a reviewed atomic alternative. No ID backfill is safe until every participating root and background path is converted and the coordinated cutover gates pass.
